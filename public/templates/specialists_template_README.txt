SPECIALISTS TEMPLATE — quick guide
==================================================================

Just TWO columns:

  Teacher Name    the specialist's name        e.g. Swanson
  Specialist      what they teach              e.g. Art, Tech, PE,
                                                    Music, Library

Everything else (working days, rooms, planning minutes, part-time,
traveling cart, two-school itinerants...) is set in the wizard after
upload — sensible defaults are applied automatically (Mon-Fri, etc.).

Tips
----
- One row per specialist.
- Edit in Excel or Google Sheets, save, and upload.
- Extra columns are fine — the importer recognizes common ones
  (phone, email, room, working days) and AI handles the rest.
